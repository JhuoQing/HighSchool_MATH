🪐 圓錐曲線

橢圓、雙曲線、拋物線都由「距離條件」定義 —— 拖動點 P 親自驗證。

實驗：距離定義的現場驗證

選擇曲線類型，然後沿著曲線拖曳點 P，觀察它到兩焦點（或焦點與準線）的距離如何保持定值：

橢圓：$\overline{PF_1} + \overline{PF_2} = 2a$（定值）。把焦距 $c$ 拉小，兩焦點靠近，橢圓越來越圓 —— $c=0$ 時就變成圓！

離心率：一個數字決定形狀

離心率 $e = \dfrac{c}{a}$ 是圓錐曲線的「身分證」：

$e = 0$：圓　｜　$0 < e < 1$：橢圓（越接近 1 越扁）　｜　$e = 1$：拋物線　｜　$e > 1$：雙曲線

關鍵公式

橢圓標準式（焦點在 x 軸）
$$\frac{x^2}{a^2} + \frac{y^2}{b^2} = 1,\quad c^2 = a^2 - b^2$$
雙曲線標準式
$$\frac{x^2}{a^2} - \frac{y^2}{b^2} = 1,\quad c^2 = a^2 + b^2,\ \text{漸近線 } y = \pm\tfrac{b}{a}x$$
拋物線標準式
$$y^2 = 4cx,\quad \text{焦點 } (c, 0),\ \text{準線 } x = -c$$
離心率
$$e = \frac{c}{a}$$
