🛩️ 空間中的平面與直線

平面由「法向量」決定方向 —— 拖曳畫面旋轉視角，從側面看平面最清楚。

實驗一：平面方程式 ax + by + cz = d

係數 $(a, b, c)$ 就是平面的法向量 $\vec{n}$（紅色箭頭，垂直於平面）；$d$ 則控制平面沿法向量方向前後平移。把視角轉到平面的「側面」，確認紅箭頭真的垂直：

只改 $d$：平面平行移動、法向量方向不變。把 $(a,b,c)$ 設成 $(0,0,1)$ 就得到水平面 $z = d$。虛線是原點到平面的最短距離（沿法向量方向）。

實驗二：直線與平面的關係

固定平面 $E: x + y + 2z = 4$，直線 $L$ 通過點 $A(-2,-1,0)$、方向向量為 $\vec{v} = (l, m, n)$。調整方向，看交點（綠點）怎麼移動 —— 什麼時候直線會平行平面而沒有交點？

關鍵在 $\vec{n}\cdot\vec{v}$：若等於 0，表示直線方向與法向量垂直 → 直線平行平面。試試 $\vec{v} = (2, 0, -1)$：$1\cdot2 + 1\cdot0 + 2\cdot(-1) = 0$。

關鍵公式

平面方程式（點法式）
$$a(x-x_0)+b(y-y_0)+c(z-z_0)=0,\quad \vec{n}=(a,b,c)$$
點到平面距離
$$\text{距離} = \frac{|ax_0+by_0+cz_0-d|}{\sqrt{a^2+b^2+c^2}}$$
直線參數式
$$\begin{cases}x = x_0 + lt\\ y = y_0 + mt\\ z = z_0 + nt\end{cases}\quad t\in\mathbb{R}$$
兩平面夾角
$$\cos\theta = \frac{|\vec{n_1}\cdot\vec{n_2}|}{|\vec{n_1}||\vec{n_2}|}$$
