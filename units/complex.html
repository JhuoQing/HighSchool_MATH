🌀 複數平面

把複數畫成平面上的點，乘法就變成「旋轉 + 伸縮」。

實驗一：複數乘法的幾何意義

拖曳 $z$（藍）與 $w$（橘），觀察乘積 $zw$（紅）：它的長度是兩者長度相乘，角度是兩者角度相加。虛線是單位圓。

把 $w$ 拖到 $i$ 的位置 $(0, 1)$：$|i| = 1$、角度 $90°$，所以乘以 $i$ 就是逆時針轉 90°而長度不變。這也解釋了為什麼 $i^2 = -1$：轉兩次 90° 就是轉 180°！

實驗二：1 的 n 次方根

方程式 $z^n = 1$ 有 $n$ 個複數解，它們把單位圓等分成 $n$ 份，連起來是正 $n$ 邊形：

由棣美弗定理，每個根的角度是 $\dfrac{360°\cdot k}{n}$。每個根自乘 $n$ 次，角度剛好繞回 $360°$ 的整數倍，也就是回到 $1$。

關鍵公式

絕對值與極式
$$|a+bi| = \sqrt{a^2+b^2},\qquad z = r(\cos\theta + i\sin\theta)$$
極式乘法
$$z_1 z_2 = r_1 r_2\big(\cos(\theta_1+\theta_2) + i\sin(\theta_1+\theta_2)\big)$$
棣美弗定理
$$(\cos\theta + i\sin\theta)^n = \cos n\theta + i\sin n\theta$$
1 的 n 次方根
$$z_k = \cos\frac{2k\pi}{n} + i\sin\frac{2k\pi}{n},\quad k = 0, 1, \ldots, n-1$$
