# 高中數學視覺實驗室 HighSchool MATH

視覺化導向的高中數學學習平台 —— 用互動實驗取代死背公式。

🔗 **線上版**：https://jhuoqing.github.io/HighSchool_MATH/

## 特色

- 🎛️ **每個概念都能動手玩**：拉滑桿、拖曳點、跑模擬，親眼看見數學
- 📚 **對齊 108 課綱**：9 大單元，涵蓋高一到高三
- 🌓 **深色／淺色模式**：一鍵切換，自動記憶
- 📱 **響應式 + 觸控支援**：手機平板都能拖曳操作
- ✅ **內建小測驗**：即時對答案與詳解，完成進度記錄在瀏覽器
- ⚡ **零框架、零建置**：純 HTML/CSS/JS + Canvas，clone 下來直接開

## 單元一覽

| 單元 | 互動實驗 |
|---|---|
| 📈 多項式函數 | 頂點式三旋鈕、三次函數根的拖曳 |
| 🚀 指數與對數 | 指對數鏡像對稱、指數成長對決 |
| ⭕ 直線與圓 | 拖兩點看斜率、直線與圓位置關係 |
| 🌊 三角函數 | 單位圓→正弦波動畫、A·sin(ωx+φ) 三參數 |
| ➡️ 平面向量 | 平行四邊形加法、內積與投影 |
| 🪐 圓錐曲線 | 拖曳點 P 驗證距離定義、離心率 |
| 🎲 排列組合與機率 | 骰子直方圖大數法則、硬幣收斂 |
| 📊 數據分析 | 拖資料點看 r 與回歸線即時變化 |
| 🔬 極限與微分 | 割線→切線、導函數描繪動畫 |

## 專案結構

```
index.html          # 首頁（單元卡片總覽）
css/style.css       # 共用樣式（深淺色主題變數）
js/common.js        # Canvas 繪圖引擎、滑桿綁定、測驗引擎、主題切換
units/*.html        # 9 個單元頁（說明 + 互動實驗 + 公式 + 測驗）
```

## 本地開發

不需要任何安裝，直接開 `index.html` 即可；或起個簡單伺服器：

```bash
python3 -m http.server 8000
# 瀏覽 http://localhost:8000
```

數學式渲染使用 [KaTeX](https://katex.org/)（CDN 載入）。
