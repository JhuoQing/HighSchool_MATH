# 高中數學視覺實驗室 HighSchool MATH

視覺化導向的高中數學學習平台 —— 用 2D／3D 互動實驗取代死背公式。

🔗 **線上版**：https://jhuoqing.github.io/HighSchool_MATH/

## 特色

- 🎛️ **18 個互動單元**：拉滑桿、拖曳點、跑模擬，每單元含公式卡與附詳解的小測驗
- 🧊 **3D 互動**：自製輕量 3D 引擎（拖曳旋轉、滾輪／雙指縮放），用於空間向量、平面與直線
- 🗺️ **課程地圖**：依 108 課綱冊別（數學 1–2、3A/4A、3B/4B、選修甲／乙）對照章節與單元
- 📝 **考試範圍**：學測數A／數B、分科測驗數甲／數乙範圍一覽，一鍵篩選範圍內單元
- 🎮 **5 款數學遊戲**：24 點、函數打靶、向量迷航、矩陣變形師、極速心算
- 🧰 **學習工具**：函數繪圖計算機（自寫安全解析器）、公式速查表
- 🌓 深色／淺色模式 · 📱 手機平板觸控支援 · ⚡ 零框架零建置

## 單元一覽

| 範圍 | 單元 |
|---|---|
| 高一必修 | 多項式函數、指數與對數、直線與圓、數列與級數、數據分析、排列組合與機率、三角函數 |
| 高二（數A・數B） | 平面向量、空間向量 🧊、空間中的平面與直線 🧊、矩陣與線性變換、條件機率與貝氏定理、圓錐曲線 |
| 高三選修（甲・乙） | 極限與微分、積分、複數平面、二項分布、線性規劃 |

## 專案結構

```
index.html            首頁（篩選搜尋、課程地圖、考試範圍、遊戲、工具、網站導覽）
css/style.css         共用樣式（深淺色主題變數、RWD）
js/data.js            全站資料：單元、課綱冊別、考試範圍、遊戲、工具
js/common.js          2D 繪圖引擎 Plot、滑桿綁定、測驗引擎、導覽列
js/plot3d.js          3D 繪圖引擎 Plot3D（投影、深度排序、平面截面）
units/*.html          互動單元
games/*.html          數學遊戲
tools/*.html          學習工具
```

### 新增單元

1. 在 `units/` 新增 `<key>.html`（可複製現有單元當範本）
2. 在 `js/data.js` 的 `UNITS` 加一筆資料（`tracks` 決定它屬於高一／數A／數B／數甲／數乙）
3. 若要出現在課程地圖，把 `key` 加進 `BOOKS` 對應章節的 `units`

首頁卡片、篩選、考試範圍統計、上下單元連結與頁尾導覽都會自動更新。

## 本地開發

不需要任何安裝，直接開 `index.html`，或起個簡單伺服器：

```bash
python3 -m http.server 8000
```

數學式渲染使用 [KaTeX](https://katex.org/)（CDN 載入）。考試範圍資訊請以大考中心當年度公告為準。
